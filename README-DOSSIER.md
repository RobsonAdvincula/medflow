## Projecto em Resumo

**MedFlow** automatiza o ciclo de atendimento de clínicas médicas via WhatsApp.  
Stack: n8n + Evolution API + HTML/JS dashboard + webhooks REST.  
Estado: Produção (implementação de referência).
